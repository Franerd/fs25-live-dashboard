# FS25 Live Dashboard — Boa Vista 4x

Calculadora estática para GitHub Pages baseada na configuração real do FastNight.

- Dia 07:00–20:00: 5x (2h36min reais)
- Noite 20:00–07:00: 80x (8min15s reais)
- Ciclo: 2h44min15s reais, sem pausas ou alterações manuais.

**Limitação:** versão inicial com sincronização manual. Não consulta automaticamente a API Fragnet. O relógio é uma estimativa até que exista um coletor HTTPS seguro.

**Segurança:** nunca colocar o parâmetro privado `code` da GIANTS no repositório, em GitHub Pages ou no JavaScript do navegador.

Para publicar: Settings → Pages → Deploy from a branch → main → /(root) → Save.
